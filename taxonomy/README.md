# 年度別 EDINET タクソノミ

抽出で使う要素ID対応表です。金融庁の他社株公開買付タクソノミは **毎年必ず変わるわけではありません**。

## 適用の考え方

公式の提出者別タクソノミ作成ガイドラインによると、他社株の公開買付届出書・意見表明などは概ね次のとおりです。

| 版 | タクソノミ日付 | 対象 |
|----|----------------|------|
| 2021年版 | 2020-11-01 | 2021-01-01以後〜2026-04-30提出 |
| 2026年版 | 2025-11-01 | 2026-05-01以後に公開買付開始公告し提出する書類 |

2022〜2025年は他社株TOBタクソノミの年次改訂がなく、2021年版を継続使用します。フォルダは年次で残してあるので、翌年の改訂が出たら `mappings/YYYY.json` を追加します。

訂正届出書・訂正報告書は、**訂正対象となった元書類と同じタクソノミ版**を使います。提出年だけで版を決めません。

## 選択順

1. XBRL/CSV 内の要素IDやファイル名から判定（`detected`）
2. 親書類の `TaxonomyYear` を継承（`parent`、訂正時）
3. 提出日と上記の適用期間から推定（`estimated`）

## フォルダ

- `manifest.json` … 年版・適用期間・検出マーカー
- `mappings/YYYY.json` … 抽出用の要素ID対応表
- `sources/YYYY/` … 公式資料の抜粋と取得元

新しい年版を足すときは、金融庁のタクソノミ要素リストから `jptoo-*` を確認し、`mappings` と `manifest.json` を更新します。
