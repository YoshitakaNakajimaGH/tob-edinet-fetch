# 年度別 EDINET タクソノミ

抽出で使う要素ID対応表です。金融庁の他社株公開買付タクソノミは **毎年必ず変わるわけではありません**。

## 適用の考え方

| 版 | タクソノミ日付 | 主な対象書類 | 提出日の目安 |
|----|----------------|--------------|--------------|
| 2013年版 | 2013-08-31 | 報告・意見・撤回・回答（270/280/290/300/260/310/320） | 〜2020-12-31 |
| 2014年版 | 2014-03-31 | 届出書（240/250） | 2014-04-01〜2020-12-31 |
| 2014年版（自社株） | 2014-07-31 | 自社株TOB 全種別 | 〜2020-12-31 |
| 2021年版 | 2020-11-01 | 他社株TOB 全種別 | 2021-01-01〜2026-04-30 |
| 2026年版 | 2025-11-01 | 2026-05-01以後に公告開始する公開買付 | 2026-05-01〜 |

2022〜2025年は他社株TOBタクソノミの年次改訂がなく、2021年版を継続使用します。

訂正届出書・訂正報告書は、**訂正対象となった元書類と同じタクソノミ版**を使います。提出年だけで版を決めません。

## 選択順

1. XBRL/CSV 内の要素IDやファイル名から判定（`detected`）
2. 親書類の `TaxonomyYear` を継承（`parent`、訂正時）
3. **書類種別＋提出日**から推定（`estimated`）— 届出は2014版、意見等は2013版など
4. 推定版の要素IDで取れない場合、**新しい版→古い版の順で要素IDをマージ**して再試行（例: 2021届出で2014要素も参照）

## フォルダ

- `manifest.json` … 年版・適用期間・書類種別・検出マーカー
- `mappings/YYYY.json` … 抽出用の要素ID対応表
- `sources/YYYY/` … 公式資料の抜粋と取得元

新しい年版を足すときは、金融庁のタクソノミ要素リストから `jptoo-*` / `jptoi_cor` を確認し、`mappings` と `manifest.json` を更新します。

## 2017年以降のデータ取得

Fetch は提出日メタデータのみなので任意の年で取得できます。Enrich（XBRL詳細化）では上記の2013/2014版マッピングにより **2017〜2020年分もラベリング可能** です。GitHub Actions の Fetch TOB ワークフローで 2017〜2020 を選び Fetch → Enrich の順で実行してください。
