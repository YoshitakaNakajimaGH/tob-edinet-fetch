# 株式交換（Stock Swap）

将来、EDINET から株式交換関連書類（有価証券届出書・臨時報告書など）を取得するパイプラインをここに追加する予定です。

## 想定する書類種別

| 書類 | docTypeCode（目安） | タクソノミ |
|------|---------------------|------------|
| 有価証券届出書 | `030` 系 | `jpsps` 等 |
| 臨時報告書 | `180` 系 | `jplvh` 等 |

TOB パイプラインは [`tob/`](../tob/) を参照してください。共有ユーティリティは [`edinet/`](../edinet/) に置きます。
